# EL 10 and EL 11 – GitHub Practice

This project demonstrates Markdown formatting, README documentation, GitHub Wiki pages, and a Code of Conduct.

## Features

- Markdown headings and formatting
- Lists and task lists
- Code examples
- Installation and usage instructions
- GitHub Wiki documentation

## Installation

Clone the repository using:

```bash
git clone https://github.com/Manasa shetty/EL10-EL11-Practice.git
cd EL10-EL11-Practice
```

Replace `YOUR-USERNAME` with your GitHub username.

## Usage

Open `README.md` on GitHub to view the formatted documentation.

Example Python code:

```python
print("Welcome to GitHub Markdown Practice!")
```

Expected output:

```text
Welcome to GitHub Markdown Practice!
```
